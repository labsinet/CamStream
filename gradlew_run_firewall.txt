Для плагіна AGP 8.5.2 потрібна Java 17 як мінімальна вимога, тому ваша Java 21 цілком підходить. Справжня причина помилки криється саме у корпоративному VPN, який ви не можете вимкнути.
У робочих мережах Gradle не знає, як пройти через корпоративний захист, або отримує від VPN самопідписаний SSL-сертифікат безпеки, якому Java не довіряє. Через це з'єднання миттєво обривається за 1 секунду.
Ось 3 рішення, які допоможуть зібрати проєкт, не вимикаючи робочий VPN:

1. Додайте сертифікати Windows у довірені для Java (найчастіша причина)

Корпоративні VPN та антивіруси часто підміняють SSL-сертифікати для перевірки трафіку. Браузер довіряє їм (бере їх із Windows), а Java — ні.
• Відкрийте файл gradle.properties у корені вашого проєкту (C:\node\CamStream\CamStream\gradle.properties).
• Додайте туди два рядки, які змусять Gradle використовувати системні сертифікати Windows:

systemProp.javax.net.ssl.trustStoreType=Windows-ROOT
systemProp.javax.net.ssl.trustStore=NONE


Будьте обачні, використовуючи код.
• Збережіть файл і спробуйте запустити .\gradlew.bat ще раз.

Якщо ви працюєте над кількома проєктами на цьому комп'ютері, щоб не додавати ці рядки щоразу в кожен новий репозиторій, ви можете перенести їх у глобальний файл налаштувань за шляхом:

C:\Users\<Ваш_Користувач>\.gradle\gradle.properties

Тоді це рішення працюватиме автоматично для всіх ваших Android- та Java-проєктів.

Встановіть вручну й подивіться відповідь

gradlew.bat assembleDebug

Встановлення через повний шлях (PowerShell, у папці проєкту)

& "$env:LOCALAPPDATA\Android\Sdk\platform-tools\adb.exe" devices

У виводі має бути ваш телефон зі статусом device. Якщо статус unauthorized, підтвердьте запит «Дозволити налагодження через USB» на екрані телефона. Якщо список порожній, перевірте кабель (потрібен кабель для передавання даних) і режим USB «Передача файлів».

Потім встановіть застосунок:

& "$env:LOCALAPPDATA\Android\Sdk\platform-tools\adb.exe" install -r app\build\outputs\apk\debug\app-debug.apk

Якщо ви змінювали шлях до SDK, його видно в Android Studio: File → Settings → Languages & Frameworks → Android SDK → Android SDK Location. Тоді папка platform-tools лежить у цьому шляху.

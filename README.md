# CamStream

Android-застосунок, який перетворює телефон на **відеосервер у локальній мережі**. Телефон знімає відео задньою камерою і транслює його по **HTTPS** у браузер на ПК. Доступ захищений логіном і паролем. Зум і фокус керуються з браузера.

Застосунок задуманий для зйомки робочого столу та дрібних деталей, наприклад мікросхем.

> Проєкт не перевірявся на великій кількості пристроїв. Поведінка камери, роздільної здатності та TLS може відрізнятися залежно від моделі телефона.

## Можливості

- Трансляція відео у форматі MJPEG прямо в браузер, без встановлення чого-небудь на ПК.
- HTTPS із самопідписаним сертифікатом (TLS 1.2) і авторизація HTTP Basic.
- Апаратний зум камери: слайдер, кнопки «+» і «−», колесо миші.
- Фокус по кліку на зображенні та кнопка «Авто AF» для повернення автофокусу.
- Вибір роздільної здатності відео зі списку, який підтримує камера телефона (за замовчуванням максимальна).
- Вибір якості JPEG (70, 85 або 95 %) і орієнтації кадру.
- Кнопка «📸 Фото MAX»: знімок у повній роздільності сенсора, який зберігається на ПК.
- Кнопка «📷 Кадр»: збереження поточного кадру відеопотоку.
- Робота у фоні як foreground-сервіс (із сповіщенням), екран телефона можна вимкнути.

## Вимоги

**Телефон**
- Android 7.0 (API 24) або новіший.
- Задня камера.
- Підключення до Wi-Fi тієї ж мережі, що й ПК.

**Для збірки**
- Android Studio.
- JDK 17 або новіший (JDK 21 підходить).
- Gradle і Android Gradle Plugin відповідних версій. Проєкт містить wrapper на Gradle 8.7 з AGP 8.5.2. Якщо у вас інші версії, залишайте свої налаштування й додавайте лише потрібні залежності.

Залежності проєкту:

| Бібліотека | Для чого |
|---|---|
| CameraX 1.3.4 | знімання відео та фото, зум, фокус |
| NanoHTTPD 2.3.1 | вбудований HTTP(S)-сервер |
| BouncyCastle (`bcprov-jdk18on`, `bcpkix-jdk18on` 1.78.1) | створення самопідписаного сертифіката |

## Збірка і встановлення

1. Відкрийте в Android Studio папку проєкту, у якій лежать `settings.gradle.kts` і `gradlew`.
2. Натисніть **Sync Project with Gradle Files**.
3. Підключіть телефон по USB. У «Параметрах розробника» ввімкніть USB-налагодження (на деяких телефонах також «Встановлення через USB»).
4. Натисніть **Run**.

Збірка з командного рядка:

```
.\gradlew.bat assembleDebug
```

APK буде в `app\build\outputs\apk\debug\app-debug.apk`.

## Використання

1. Запустіть застосунок на телефоні.
2. Задайте логін, пароль (щонайменше 6 символів) і порт (за замовчуванням `8443`).
3. Виберіть роздільну здатність, якість JPEG та орієнтацію.
4. Натисніть **«Запустити трансляцію»** і дайте дозвіл на камеру та сповіщення.
5. Застосунок покаже адресу виду `https://192.168.x.x:8443`.
6. Відкрийте цю адресу в браузері на ПК у тій самій Wi-Fi мережі.
7. Браузер покаже попередження про недовірений сертифікат. Це очікувано, бо сертифікат самопідписаний. Натисніть «Додатково → Продовжити».
8. Введіть логін і пароль.

Застосунок також показує SHA-256 відбиток сертифіката. Його можна порівняти з відбитком у властивостях сертифіката в браузері.

## Керування в браузері

| Дія | Як |
|---|---|
| Зум | слайдер, кнопки «+» і «−», колесо миші над зображенням |
| Фокус у точці | клік по зображенню (фокус і експозиція фіксуються) |
| Повернути автофокус | кнопка «Авто AF» |
| Поточний кадр | кнопка «📷 Кадр» |
| Фото в максимальній роздільності | кнопка «📸 Фото MAX» |
| Повний екран | кнопка «⛶» |

## HTTP-інтерфейс

Усі адреси потребують авторизації.

| Адреса | Опис |
|---|---|
| `/` | веб-сторінка керування |
| `/stream` | MJPEG-потік |
| `/snapshot` | останній кадр відеопотоку (JPEG) |
| `/photo` | фото в максимальній роздільності (JPEG) |
| `/api/info` | поточний, мінімальний і максимальний зум (JSON) |
| `/api/zoom?ratio=2.5` | встановити зум |
| `/api/focus?x=0.5&y=0.5` | сфокусуватися в точці (координати 0..1) |
| `/api/autofocus` | повернути автофокус |

Приклад збереження кадру з командного рядка:

```
curl -k -u admin:пароль https://192.168.x.x:8443/snapshot -o frame.jpg
```

## Поради для зйомки дрібних деталей

- Камера не сфокусується ближче за мінімальну дистанцію фокусування (зазвичай 8–15 см, інколи 30 см). Краще відсунути телефон і збільшити зумом.
- Для максимальної деталізації використовуйте «Фото MAX». Відеопотік обмежений швидкістю Wi-Fi і швидкістю JPEG-кодування.
- Чим більша роздільність відео, тим менше кадрів на секунду. На 12 МП це приблизно 2–5 кадрів/с, на 1080p можна очікувати до 25.
- Закріпіть телефон на штативі й забезпечте рівномірне світло. Блики на корпусах мікросхем можна зменшити розсіяним світлом.
- Клік по зображенню фіксує фокус, поки не натиснути «Авто AF».

## Безпека

- Сертифікат самопідписаний, тому браузер завжди видає попередження. Трафік при цьому шифрується.
- Логін і пароль передаються по HTTPS. Пароль зберігається в налаштуваннях застосунку у відкритому вигляді.
- Приватний ключ і сертифікат зберігаються у приватній папці застосунку (`tls.p12`) і створюються при першому запуску.
- Сервер слухає всі інтерфейси телефона. Використовуйте довгий пароль і не відкривайте порт назовні (не пробрасуйте його на роутері).
- Невдалі спроби входу затримуються на 0,5 с, повного захисту від підбору пароля немає.

## Обмеження

- Лише задня камера (основний об'єктив), без звуку.
- Лише один відеопотік із вибраними параметрами. Щоб змінити роздільність, зупиніть і запустіть трансляцію знову.
- Якщо телефон не підтримує одночасно відео та фото максимальної роздільності, фото вимикається, а відео працює.
- Якщо роутер ізолює клієнтів Wi-Fi (client isolation, гостьова мережа), ПК не побачить телефон.
- Емулятор Android не підходить: у ньому немає реальної камери з макрофокусом і максимальною роздільністю, а його мережа ізольована.

## Вирішення проблем

| Проблема | Що перевірити |
|---|---|
| Gradle не знаходить плагін `com.android.application` | вимкнений Offline mode, доступ до `dl.google.com`, VPN/антивірус, JDK 17+ |
| `Unresolved reference 'bouncycastle'` | у `app/build.gradle.kts` немає залежностей BouncyCastle (див. таблицю вище), потім Sync |
| Застосунок не встановлюється | USB-налагодження і «Встановлення через USB», `adb devices`, кабель для передачі даних |
| `adb` не знайдено у PowerShell | запускайте за повним шляхом: `& "$env:LOCALAPPDATA\Android\Sdk\platform-tools\adb.exe"` |
| Браузер: «хост розірвав з'єднання» | відкривайте саме `https://`, перевірте Logcat (тег `CamStream`, фільтр `package:mine`) |
| Немає відео | дозвіл на камеру, Wi-Fi в одній мережі, ізоляція клієнтів у роутері |
| Дуже повільне відео | зменште роздільність або якість JPEG |

## Структура проєкту

```
app/src/main/
├── AndroidManifest.xml
├── assets/index.html                      веб-інтерфейс для ПК
└── java/com/example/camstream/
    ├── MainActivity.kt                    екран налаштувань
    ├── StreamService.kt                   камера, кодування JPEG, зум, фокус, фото
    ├── MjpegServer.kt                     HTTPS-сервер, авторизація, ендпоінти
    ├── FrameHub.kt                        передача кадрів клієнтам
    ├── TlsHelper.kt                       самопідписаний сертифікат
    └── CameraSizes.kt                     список підтримуваних роздільностей
```

## Дозволи

- `CAMERA` для зйомки.
- `INTERNET` і `ACCESS_WIFI_STATE` для сервера та визначення IP-адреси.
- `FOREGROUND_SERVICE` і `FOREGROUND_SERVICE_CAMERA` для роботи камери у фоні.
- `POST_NOTIFICATIONS` для сповіщення про активну трансляцію (Android 13+).
- `WAKE_LOCK`, щоб телефон не засинав під час трансляції.
